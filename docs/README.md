# Guides techniques et annexes

La documentation destinée à l'évaluation est maintenant regroupée dans [`doc/`](../doc/README.md), avec un [rapport de synthèse](../doc/rapport-projet.md) et un fichier `documentation.md` par étape. Commencer par ce dossier pour lire le projet dans l'ordre du guide PDF.

Ce répertoire conserve les références techniques utilisées par ces chapitres :

| Référence | Usage |
| --- | --- |
| [Architecture](architecture.md) | Composants, flux et modèle de données |
| [Contrat de mesure](contracts/measurement-contract.md) | Champs et contraintes d'entrée |
| [API](api.md) | Routes, statuts et exemples |
| [Analytics](analytics.md) | Formules, règles et limites |
| [Docker](docker-databases.md) | Démarrage, santé et persistance |
| [Démonstration de cours](course-demo.md) | Préparation des capteurs, simulation et lectures |
| [Performance](performance.md) | Résultats Docker du 5 novembre, protocole et JSON bruts |
| [Observabilité](observability.md) | Ports Actuator et signification des métriques |
| [Sécurité](security.md) | Profils, accès exposés et limites |
| [Tests](tests.md) | Résultats datés et scénarios |
| [Progression](progress.md) | Validations et historique de travail |

`superpowers/` contient des plans et décisions de travail. Ce ne sont pas les chapitres à remettre comme explication finale du projet. Les documents historiques peuvent conserver des états antérieurs ; les chapitres de `doc/` les replacent dans leur chronologie.
